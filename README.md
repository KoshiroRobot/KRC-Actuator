# KRC Actuator

Design files for the actuator shown in the video.

- `cad/` STEP
- `pcb/` EAGLE files, schematic, Gerber, BOM, CPL
- `firmware/` STM32CubeIDE project and prebuilt image
- `host/` Raspberry Pi tools
